# 玄幻題材完整規則手冊

---

## I. 玄幻概述

**定義**：架空世界、完整的修為體系、超自然力量系統、宏大的世界觀。

**核心特徵**：
- 魔法/修煉系統具有明確的階級與規則
- 主角通過修煉逐步變強（爽點驅動）
- 傳統中國文化元素（靈氣、道、劍、秘境等）
- 超越現實的視野與終極使命

---

## II. 章節類型分類

### 1. 戰鬥章

**定義**：展現直接衝突、能力對抗的章節

**特徵**：
- 包含明確的敵手與戰鬥過程
- 以主角勝利或策略突破結尾
- 涉及能力展示與升級暗示

**常見結構**：
```
遭遇敵手 → 評估實力 → 戰鬥過程 → 智鬥/蠻力突破 → 勝利與收益
```

**節奏要點**：
- 戰鬥不超過3000字（保持節奏感）
- 每場戰鬥應有新技能或新思路的展現
- 損傷與消耗應有記錄（particle-ledger）

**爽點類型**：
- 打臉：主角以弱勝強，對手意外敗北
- 碾壓：實力懸殊，主角輾轉敵手
- 智鬥：戰術推演，主角出奇致勝

**舉例**：《大主宰》第12章 蓮火靈戲 - 蕭炎與韋素偽戰，以靈火妙用逆轉局勢

**撰寫時限**：
- 短戰鬥（同階敵手）：1500-2000字
- 中戰鬥（跨階敵手）：2000-3000字
- 長戰鬥（關鍵敵手或多人）：3000-4000字

---

### 2. 布局章

**定義**：埋下伏筆、引入新人物或新環境、推進陰謀線的章節

**特徵**：
- 信息密度高
- 以懸念結尾
- 多角色視角或對話推進

**常見結構**：
```
環境描寫 → 人物登場 → 對話/事件 → 伏筆或信息揭露 → 懸念終局
```

**節奏要點**：
- 每個布局章應埋下2-3個新伏筆（pending-hooks）
- 推出新角色時應明確其立場（敵/友/不確定）
- 信息不能過於直白，需層次披露

**常見模式**：
- 秘密會議（陰謀揭露）
- 新人物入場（角色關係擴展）
- 環境發現（地點線推進）
- 信件/傳聞（信息遠傳）

**舉例**：《斗破蒼穹》第50章 煉藥師公會 - 介紹藥老、揭露實力等級制、埋下秘境伏筆

**撰寫時限**：2000-3500字

---

### 3. 過渡章

**定義**：時間跳躍、日常修煉、狀態穩定的章節

**特徵**：
- 相對平靜，無重大衝突
- 推進時間線，建立日常節奏
- 為重大事件蓄勢

**常見結構**：
```
開局狀態 → 日常活動 → 小規模互動 → 狀態提升 → 新機遇或預兆
```

**節奏要點**：
- 避免連續3章過渡（讀者容易疲勞）
- 應在過渡中暗示後續重大事件
- 角色成長應有量化記錄（particle-ledger）

**常見場景**：
- 修煉日常（境界推進）
- 人物閒敘（關係深化）
- 環境探索（世界觀擴展）
- 準備階段（為大事件做準備）

**舉例**：《大主宰》第15章 修煉 - 蕭炎持續修煉，靈力穩步增長，為後續突破蓄勢

**撰寫時限**：1500-2500字

---

### 4. 回收章

**定義**：兌現伏筆、回報承諾、推進重要人物線的章節

**特徵**：
- 高情感衝擊力
- 包含長期懸念的解答
- 人物關係發生轉折

**常見結構**：
```
期待氛圍 → 真相揭露/承諾兌現 → 角色反應 → 後續影響
```

**節奏要點**：
- 重要伏筆的回收應不早於埋下後的5-8章
- 回收時應有新的懸念接手，避免敘事真空
- 情感應與伏筆重要性相匹配

**常見回收方式**：
- 秘密揭露（身份、過去、真相）
- 承諾兌現（贈禮、幫助、復仇）
- 關係升溫（親情、愛情、友情的深化）
- 能力進化（新技能習得、境界突破）

**舉例**：《斗破蒼穹》第200章 狀態回收 - 蕭炎與薩烏瑞的對決，融合多個伏筆的兌現

**撰寫時限**：2500-4000字（允許較長，承載更多情感與信息）

## V. 節奏規則

### 5.1 反饋週期

**核心規則**：三章內必有明確反饋

**定義**：主角的行動、決策或努力應在3章內產生可感知的結果

**反饋類型**：
- **升級反饋**：實力、境界、資源提升
- **情感反饋**：關係變化、感情推進
- **信息反饋**：伏筆推進、謎團解答
- **環境反饋**：地位提升、局勢變化
- **衝突反饋**：敵人升級、新威脅出現

**舉例（反面）**：
```
第10章：主角下定決心修煉秘法
第11章：在修煉中（無反饋）
第12章：仍在修煉中（無反饋）
第13章：才開始展現成效（超過3章，讀者容易失興趣）
```

**舉例（正面）**：
```
第10章：主角下定決心修煉秘法
第11章：出現瓶頸，需要外界幫助（進度反饋 + 新伏筆）
第12章：得到幫助，秘法初成（升級反饋 + 關係反饋）
第13章：新秘法首度戰鬥驗證（戰鬥反饋 + 爽點）
```

---

### 5.2 爽點分布

**每章應含一個爽點**，類型循環分布

**推薦爽點序列**（每3章為一輪）：
```
第1章：打臉/升級
第2章：收益兌現/身份揭示
第3章：智鬥碾壓/底牌亮出
（第4-6章循環重複）
```

**避免連續**：不應連續2章相同類型的爽點

## VI. 爽點類型詳解

### 1. 打臉

**定義**：主角以更聰慧、更努力或更幸運的方式擊敗看似更強的對手

**要素**：
- 對手輕視或嘲笑主角
- 主角隱藏真實實力或新策略
- 戲劇化的局勢反轉

**範例**：
```
蕭炎 vs 蕭鼎：蕭鼎自負地認為蕭炎廢物一個，但不知蕭炎已習得新秘法，
一舉逆轉，將蕭鼎擊敗。讀者與蕭鼎同時驚訝。
```

**字數**：1500-2500字

---

### 2. 升級突破

**定義**：主角突破修為瓶頸、習得新功法、獲得新道具、開啟新能力

**要素**：
- 明確的修為境界跳躍
- 視覺化的力量提升（氣勢、光效、異象）
- 主角的主觀感受（暢快感、掌控感）

**範例**：
```
凌雲衝擊築基期的最後一層瓶頸。三次失敗後，在白月的靈力支持下，
忽然領悟了「凝聚真元」的訣竅。一股澎湃的力量在體內炸裂，
凌雲成功晉升築基中期。天眼光芒大盛，視野頓時清晰百倍。
```

**字數**：2000-3000字

---

### 3. 收益兌現

**定義**：主角在前期努力（修煉、冒險、備戰）終於轉化為立竿見影的戰鬥優勢

**要素**：
- 前期鋪墊與後期爆發的時間跨度感（至少5章以上）
- 在關鍵時刻的觀眾驚喜感
- 舊技能組合出新效果

**範例**：
```
第5章：凌雲習得「流火掌法」
第6-10章：日常修煉與應用
第11章：與秦家對手交手，深層應用流火掌法：火焰不只傷敵，
還能灼燒對方靈力通道，一招制敵。
```

**字數**：1800-2500字

---

### 4. 智鬥碾壓

**定義**：主角通過戰術、心理戰、環境利用等手段摧垮對手，而非純粹蠻力

**要素**：
- 主角的聰慧與實力兼備
- 對手的致命弱點被充分利用
- 讀者的「看得出來，對手卻看不出來」的優越感

**範例**：
```
凌雲 vs 青蟹妖獸：妖獸力量遠勝凌雲，但凌雲察覺到妖獸對靈力極度敏感。
凌雲故意散發虛假的靈力波動，誘導妖獸攻向空處，
然後真身從側面發動致命一擊。
```

**字數**：2000-3000字

---

### 5. 身份揭示

**定義**：主角的身份、出身、秘密在關鍵時刻被揭露或自我確認，改變局勢認知

**要素**：
- 長期伏筆的回收
- 角色的主觀視角轉變
- 可能帶來的敵友重新評估

**範例**：
```
凌雲在關鍵時刻，天眼光芒大作，古老的記憶碎片閃現。
秦管家看到這一幕，瞳孔收縮：「轉世者？」
凌雲意識到自己身份的真相，從迷茫走向確定。
```

**字數**：2500-3500字

---

### 6. 底牌亮出

**定義**：主角動用隱藏的、一直未曾展露的強大能力或道具，逆轉絕望局勢

**要素**：
- 前期的合理埋伏（讀者能回溯出線索，卻未預期到此刻用出）
- 能力的強大程度足以驚人
- 使用後的代價或後遺症（不能無限用）

**範例**：
```
凌雲被魔心宗刺客逼至絕境。忽然，他喚醒了天眼內的古老禁術：
「天眼·真相視界」。此刻，他能看到敵人所有靈力的流動軌跡。
主動權瞬間逆轉。但使用後，凌雲陷入了三天的昏迷。
```

**字數**：2000-3500字

| 3層 | 練氣後期 | 靈氣運用純熟 | 150年 |

---

### 7.2 跨階戰鬥規則

**同階內戰鬥**：任何一方都可能勝利（技巧、道具、幸運都重要）

**跨一階戰鬥**：
- 高階者勝面約70%（但主角可通過爽點突破此概率）
- 低階者需要：新道具 + 新秘法 + 外援，才能勝

**跨兩階戰鬥**：
- 幾乎不可能勝利（除非使用禁術或發動底牌，且有代價）
- 主角應傾向逃脫而非對抗

**跨三階以上**：
- 完全碾壓，不應發生對抗

**舉例**：
```
凌雲：築基初期
青蟹妖獸：築基中期（高一階）
結果：凌雲勝（但付出大代價，並觸發了新秘法領悟）

凌雲：築基初期
魔心宗刺客：金丹初期（高三階）
結果：凌雲不敵，被迫逃脫或被救援
```

---

### 7.3 修為晉級規則

**晉級時間間隔**：
- 練氣階段：每階1-2章（快速）
- 築基階段：每階2-4章（正常）
- 金丹階段：每階4-8章（緩慢）
- 元嬰以上：每階8-16章（極緩）

**晉級條件**：
- 境界感悟（主角領悟新的修煉訣竅）
- 資源積累（particle-ledger 的靈石、丹藥達到閾值）
- 關鍵事件（瀕死突破、感情觸發、秘寶獲得）
- 機遇出現（名師教導、秘地尋寶、古籍參悟）

**違反規則的表現**：
```
【違反】第1章練氣初期，第2章立即築基（無關鍵事件支撐）
【合理】第1-5章練氣進度，第6章遭遇危機觸發瓶頸領悟，
        第7章確認晉升築基初期
```

## VIII. 資源衰減公式

玄幻小說中，反覆使用同一資源（如修煉地點、靈草、秘法）會產生邊際效應遞減。

**公式**：
```
收益 = 基礎值 × max(0.3, 1 - 0.15 × (N - 1))
```

**變數**：
- **N**：該資源被使用的次數
- **基礎值**：首次使用時的標準收益
- **0.3**：下限係數（永遠不低於基礎值的30%）
- **0.15**：衰減速率

**計算示例**：

| 次數 | 係數 | 計算 | 結果 |
|------|------|------|------|
| 1 | 1.0 | 100 × 1.0 | 100 |
| 2 | 0.85 | 100 × 0.85 | 85 |
| 3 | 0.70 | 100 × 0.70 | 70 |
| 4 | 0.55 | 100 × 0.55 | 55 |
| 5 | 0.40 | 100 × 0.40 | 40 |
| 6 | 0.30 | max(0.3, 0.25) = 0.3 | 30（定底） |
| 7+ | 0.30 | max(0.3, 負) = 0.3 | 30（保持） |

**應用場景**：
- 修煉地點的靈氣吸收
- 相同秘法的反覆使用
- 同一敵人的多次交手
- 重複資源的經濟價值

**文本表現**：
```
第一次在靈泉修煉：吸收靈氣100單位
第二次在靈泉修煉：靈泉的靈氣似乎耗弱了，只吸收85單位
第三次在靈泉修煉：靈泉已被反覆開採，效果下降到70單位
（……依次遞減……）
第六次及以後：靈泉恢復緩慢，穩定在每次30單位
```

## IX. 玄幻題材十大禁忌

### 1. 低等級邏輯BUG

**禁忌**：主角境界明顯低於敵手，卻無理由地屢屢勝利

**正確做法**：
- 給主角新秘法 / 新道具 / 新認知
- 或明確敵手有致命弱點（本應知曉但忽視）
- 或引入外援力量
- 每次勝利都應有故事原因支撐

---

### 2. 修為進度失控

**禁忌**：主角修為上升速度超越故事容納的時間

**正確做法**：
- 保持修為晉級間隔的規律性（見 7.3）
- 在 particle-ledger 中明確每次晉級的資源投入
- 讀者能回溯出「為什麼主角在第X章突然強了」

---

### 3. 道具憑空出現

**禁忌**：關鍵道具、秘法、功法無前期鋪墊，在需要時突然取出

**正確做法**：
- 在 pending-hooks 中埋伏每一件關鍵道具的來源線索
- 至少在使用前3-5章暗示其存在
- 獲得道具時應有明確的故事事件

**違反舉例**：
```
【違反】第20章主角突然拿出「天地鼎」來煉製丹藥，此前從未提及
【正確】第12章提及「古老傳說中有件天地鼎」→ 第15章發現線索
        → 第18章探索秘地尋獲 → 第20章開始使用
```

---

### 4. 設定自相矛盾

**禁忌**：同一項設定在不同章節有相悖的表述

**正確做法**：
- 在 current-state.md 中列出所有已確立的設定
- 使用搜索工具在全文檢查一致性
- 如需改動設定，應明確在章節中交代改動原因

**舉例檢查清單**：
```
□ 金丹期修者的壽命始終為500年
□ 幽冥沼澤始終位於東南方向
□ 白月與秦小姐的首次相遇始終是第4章
□ 靈石礦的總儲量始終不超過particle-ledger設定值
```

---

### 5. 感情線崩壞

**禁忌**：戀情或親情的推進脫離人物性格與事件邏輯

**正確做法**：
- 使用 emotional-arcs.md 跟蹤角色情緒變化
- 每一次感情升溫都應有對應事件觸發
- 使用 character-matrix 確保相遇頻率與親密度相匹配

**違反舉例**：
```
【違反】凌雲與白月只有3次對話，卻在第10章宣布「我愛你」
【正確】凌雲與白月經歷8次相遇，每次接觸都推進感情，
        到第15章時關係才升溫為「伴侶」（未明說戀愛）
```

---

### 6. 反派無動機

**禁忌**：敵手追殺主角、設置陰謀，卻無明確動機說明

**正確做法**：
- 每個敵手都應有明確的目標與利益
- 動機應在敵手首次登場或第一次衝突後5章內交代
- 使用 character-matrix 記錄敵友關係的成因

**舉例**：
```
【違反】魔心宗宗主莫名其妙地追殺凌雲
【正確】魔心宗宗主因凌雲搶走了象徵宗門權力的「天陨石核」
        而視其為眼中釘。此動機在第8章時由第三方透露。
```

---

### 7. 世界觀崩潰

**禁忌**：大陸政治、宗派勢力、靈氣流向在故事推進中無故改變

**正確做法**：
- 在 current-state.md 中列出所有勢力的立場與聯盟關係
- 任何立場改變都應有故事事件驅動
- 政治變化應提前3-5章埋伏信號（布局章）

---

### 8. 爽點疲勞

**禁忌**：爽點過於頻繁（每章都升級、每章都打臉），導致讀者適應閾值上升

**正確做法**：
- 遵循爽點分布規則（見 5.2）
- 爽點應循環不同類型，避免重複
- 監測讀者反饋，調整爽點強度

---

### 9. 配角活力消亡

**禁忌**：配角在出現2-3次後消失，或性格變平面化

**正確做法**：
- 使用 subplot-board 為配角設定獨立的發展線
- 在 character-matrix 中記錄配角的多次相遇
- 每個配角都應有明確的目標（不只是陪襯主角）

---

### 10. 敘事節奏崩潰

**禁忌**：連續5章無明確反饋、或連續3章皆為過渡章

**正確做法**：
- 遵循反饋週期規則（見 5.1：三章內必有反饋）
- 在 chapter-summaries 中監測章節類型分布
- 若發現異常，提前調整

**檢查模板**：
```
第10-12章：過渡 → 過渡 → 過渡（❌ 違反，應調整第12章為戰鬥或回收）
第10-12章：過渡 → 戰鬥 → 過渡（✓ 合理）
```

## X. 語言鐵律

### 10.1 文言文使用規則

**允許場景**：
- 古籍與秘法描述
- NPC的正式對白（長老、宗主、教導者）
- 環境的莊嚴氛圍營造

**禁用場景**：
- 主角的內心獨白（應為現代心理描寫）
- 日常人物對話（應為口語化的現代中文）
- 動作描寫的主幹（應為白話敘事）

**範例**：
```
【允許】秘籍上古籍載：「凝聚真元，乃修士之關鍵……」
【允許】長老教訓：「爾乃小輩，慎勿自大。吾輩修道千年……」
【禁用】主角想：「余不能退卻，必須奮起……」（應為「我不能退，必須……」）
【禁用】日常對話：「汝欲何往？」（應為「你要去哪？」）
```

---

### 10.2 東方想像詞彙守則

**地名與方向**：
- 使用「東南西北」而非「left / right」
- 使用「秘境、寶地、禁地」而非「place」

**修為相關**：
- 統一使用「靈氣、真元、法力、靈韻」等詞彙
- 避免混用西方「魔法、魔力」概念
- 晉級用語：「突破、晉升、進階」

**宗教語境**：
- 修道者：「修士、道友、前輩」
- 聚集地：「宗派、門派、世家」
- 聖物：「靈寶、靈物、古籍」

**禁止混搭**：
```
【違反】凌雲的魔法（Magic）發動了……
【正確】凌雲的靈術發動了……

【違反】秘境內有一個 Dungeon……
【正確】秘境內有一片禁地……
```

---

### 10.3 感官描寫節制

**色彩詞彙**：
- 允許每千字出現：靈光（藍、紫、金、黑）3-4次
- 禁用過於具體的 RGB 值或西方色彩名
- 優先使用天然物體比喻（「如玉般潔白」而非「pure white」）

**聲音描寫**：
- 允許：嗡鳴、劍鳴、龍吟、風哨
- 禁用：「咻」、「嗖」等擬聲詞過多（每千字不超過2次）

**觸覺描寫**：
- 強調「靈力流動感」而非「物理質感」
- 例：「靈力如湍流般衝過經脈」而非「如冰水般冷刺」

---

### 10.4 對白風格

**主角對白**：
- 應帶有疑惑、成長感（尤其初期）
- 避免過於成熟或高傲（除非經歷足夠的經歷）

**NPC對白**：
- 老者：莊重、教導性
- 同齡朋友：親近、口語化
- 敵手：嘲諷、傲慢或謹慎（取決於性格）

**禁忌**：
```
【違反】凌雲（初期築基修士）：「此劇本實乃拙劣之作，吾必整頓山河！」
        （過於高傲，不符合成長心路）
【正確】凌雲（初期築基修士）：「我……我會變強的。」
        （帶有謹慎與決心）
```
