# 仙俠題材完整規則手冊

---

## I. 仙俠題材概述

**定義**：中國古代傳說背景，融合武俠、修仙、歷史想像的東方奇幻題材。

**核心特徵**：
- 修仙體系與武俠人生並存
- 道德困境與江湖恩怨交織
- 古典中國文化元素（琴棋書畫、儒道佛融合、歷史典故）
- 個人修為與社會責任的平衡

**與玄幻的差異**：
- 玄幻：魔法系統、超越時代、宏大世界觀
- 仙俠：修仙系統、古代背景、人性刻畫、江湖故事

**常見子類型**：
- 劍俠文（以劍道為核心，強調劍術與人生哲學）
- 隱居仙俠（遠離塵世，修仙與尋道）
- 江湖仙俠（武俠色彩濃厚，伏龍鳳雛式的人物）
- 歷史仙俠（融合真實歷史背景與修仙設定）

---

## II. 章節類型分類

### 1. 決鬥章

**定義**：兩位武林高手的對決，融合劍法、內力、修為與品性的綜合較量

**特徵**：
- 涉及複雜的招式與心法運用
- 往往決定了江湖局勢或個人聲譽
- 結果帶有道德或宿命的暗示

**常見結構**：
```
決鬥前的蓄勢 → 招式交換與試探 → 核心戰鬥 → 精妙轉折 → 勝負與後續
```

**節奏要點**：
- 決鬥應有明確的勝負條件（殺死、認輸、棄權）
- 高手過招應體現智謀與品性（不只是蠻力）
- 敗者應有說得過去的失敗原因（修為低、陷入心魔、對手更強等）

**爽點類型**：
- 劍法極致：展現獨特的劍術境界
- 品性勝利：以高潔的品格鎮壓對手（如：以不殺之心勝殺心者）
- 棋局推翻：發現對手有隱藏目的，改變對決的意義

**舉例**：李尋歡與上官金虹的決鬥（《小李飛刀》第2部），刀法與品性的綜合對抗

**撰寫時限**：2500-4000字

---

### 2. 劫難章

**定義**：主角面臨人生的關鍵考驗——修煉瓶頸、心魔、劫難、或道德抉擇

**特徵**：
- 高情感張力
- 涉及靈魂層面的選擇
- 結果影響主角的修為與人格

**常見結構**：
```
劫難出現 → 主角面臨絕望 → 內心掙扎與頓悟 → 度劫成功或失敗 → 蛻變或遺憾
```

**節奏要點**：
- 劫難應源於主角的既有矛盾（不能憑空出現）
- 度劫過程應體現主角的品性
- 成功或失敗都應改變主角的人生軌跡

**常見劫難類型**：
- 修為瓶頸：境界突破前的困頓與頓悟
- 心魔入侵：過往創傷或執念的回現
- 天災人禍：失去重要之人或物品
- 道德困境：必須在兩個都難受的選擇中抉擇

**舉例**：主角為了救一個人而被迫殺死無辜之人，陷入「傷害何人都不對」的困境

**撰寫時限**：2500-4000字

---

### 3. 修煉章

**定義**：主角進行閉關修煉、參悟功法、突破境界的章節

**特徵**：
- 內省與靜思為主
- 可能涉及冥想、悟道、參經等場景
- 時間跨度可能較大（數天到數月）

**常見結構**：
```
修煉開始與目標設定 → 漸進過程中的困難與突破 → 頓悟時刻 → 境界確認與感受
```

**節奏要點**：
- 修煉過程不應過於冗長（應濃縮為500-1500字的核心片段）
- 應包含修煉者的主觀感受（力量感、身體變化、靈魂體驗）
- 突破時應有環境異象（光芒、聲響、天候變化）

**常見場景**：
- 在聖地或靈地修煉（吸收天地靈氣）
- 參悟古籍或師傅傳授
- 面對自然與極限
- 在危機中的被迫突破

**舉例**：主角在大雪中閉關三月，最終頓悟心法第七層，身上積雪忽化，衣衫飄飄

**撰寫時限**：1500-2500字

---

### 4. 人事章

**定義**：主角處理人際關係、江湖恩怨、宗派事務的章節

**特徵**：
- 對白與文戲為主
- 涉及人物之間的複雜情感與利益
- 常見於序、中盤、終局前的序曲

**常見結構**：
```
人物聚集或衝突 → 對話與試探 → 利益博弈或感情糾葛 → 新的關係狀態確立
```

**節奏要點**：
- 應避免冗長說教式的對話
- 每個人物應有明確的立場與目標
- 對話應推進情節或揭示角色

**常見場景**：
- 宗派決議（長老會議、弟子大會）
- 師徒互動（教導、衝突、和解）
- 知己相聚（傾心交流、互相鼓勵）
- 敵手相遇（試探、威脅、對峙）

**舉例**：主角與師尊就修仙之道的目的發生根本分歧，師徒關係開始裂隙

**撰寫時限**：1800-2500字

---

### 5. 行走章

**定義**：主角在江湖中遊歷、探險、尋求機遇與真理的章節

**特徵**：
- 環境描寫與冒險為主
- 可能包含小型戰鬥或遭遇
- 時間跨度通常較大（跋山涉水數日）

**常見結構**：
```
出發與目標 → 路途中的遭遇 → 新發現或新人物 → 到達目的地或改變計畫
```

**節奏要點**：
- 應呈現真實的旅途艱辛（饑餓、疲勞、危險）
- 景色描寫應與主角心境相呼應
- 每日的遭遇應有故事價值（不只是流水賬）

**常見場景**：
- 江湖流浪與尋訪（找名師、找失散之人、找傳說中的地點）
- 險地探險（秘境、禁地、危險山區）
- 隱居與日常（遠離塵世的修煉與思考）

**舉例**：主角為尋找失傳劍法，不辭艱辛登上蜀山，沿途遇難友、識高人、解誤會

**撰寫時限**：2000-3500字

---

### 6. 宿命章

**定義**：揭露主角身世、預言應驗、或歷史大背景浮現的關鍵章節

**特徵**：
- 高信息密度
- 改變讀者與主角的世界認知
- 帶有哲學或宿命的沉重感

**常見結構**：
```
危機或疑惑浮現 → 真相漸次披露 → 衝擊與反思 → 新的人生使命或悲劇認知
```

**節奏要點**：
- 身世揭露應在前期埋伏足夠線索
- 應給予主角與讀者消化的時間
- 揭露後應立即推進新的衝突

**常見內容**：
- 身世秘密（非凡出身、轉世身份、隱藏血脈）
- 歷史宿命（註定的對手、天選之人的使命）
- 道德困局（親人與道義的衝突、不可調和的立場）

**舉例**：主角發現自己是被謀殺的前任聖人的轉世，肩負著阻止大劫難的使命

**撰寫時限**：2500-4000字

## V. 節奏規則

### 5.1 決鬥與靜修的節奏交替

**核心規則**：動靜結合，避免連續激烈衝突

**推薦節奏**（每6章為一輪）：
```
第1章：決鬥/危機（動）
第2章：人事/探討（靜）
第3章：修煉/悟道（靜）
第4章：行走/冒險（動）
第5章：人事/江湖（靜）
第6章：決鬥/對抗（動）
```

**禁忌**：
- 連續3章都是決鬥（讀者疲勞）
- 連續3章都是靜修（讀者無聊）
- 整卷都是宗派事務（無戲劇張力）

---

### 5.2 品性與修為的雙向成長

**核心規則**：修為提升應伴隨品性變化

**正確範例**：
```
第1-5章：主角修為突破筑基期，但性格變得傲慢
第6-10章：遭遇重大挫折，修為停滯，但品性反思
第11-15章：放下執念，修為與品性同步提升
```

**禁忌**：
```
【違反】主角修為日日精進，但性格始終不變（不符合仙俠的修行邏輯）
【正確】主角每次修為突破都帶來心態的改變（覺悟新層次）
```

| 7-9層 | 金丹真人 | 可避免生老病死，與天地共鳴 | 500-800年 |

| 等級 | 特徵 | 修為要求 | 殺傷力 |
|------|------|--------|-------|
| 凡劍 | 普通劍法，招式為主 | 武者 | 對等修為內的對手 |

---

### 6.3 劍法進度規則

**每次劍法突破應有對應的故事事件**：
```
發現瓶頸 → 尋找突破契機 → 經歷磨難 → 頓悟新境界 → 首次應用與驗證
```

**時間間隔**：
- 凡劍→秘傳：1-3章（快速）
- 秘傳→劍意：4-8章（中速）
- 劍意→劍心：8-16章（緩慢）
- 劍心→道劍：16-32章（極緩，決定全書進度）

## VII. 仙俠十大禁忌

### 1. 劍法無邏輯

**禁忌**：主角突然習得比修為應有的更高級劍法，無故事原因

**正確做法**：
- 高級劍法應來自：名師傳授、秘籍發現、機遇領悟
- 每次習得都應有對應章節交代
- 修為限制劍法（築基期不能用金丹期才能用的劍法）

---

### 2. 品性崩潰

**禁忌**：主角為了勝利而放棄原有的品性操守，無故事反思

**正確做法**：
- 若主角做出失節的行為，應有內心的悔恨與後續的修復
- 品性變化應與修為進度相伴
- 每次妥協都應有代價（心傷、修為停滯等）

---

### 3. 江湖局勢混亂

**禁忌**：宗派勢力、敵友關係在故事推進中無故改變

**正確做法**：
- 在 current-state.md 中列出各方勢力與立場
- 任何立場改變都應有故事事件驅動
- 大的局勢變化應提前3-5章埋伏信號

---

### 4. 身世揭露倉促

**禁忌**：主角身份秘密在無足夠線索的情況下被揭露

**正確做法**：
- 身世揭露前應至少埋伏3-5個相關線索
- 揭露應在故事的適當節點（不能太早或太晚）
- 揭露後應立即推進新的衝突

---

### 5. 師徒關係虛假

**禁忌**：師尊與弟子的互動表面化，無實質的傳承或衝突

**正確做法**：
- 師徒之間應有明確的傳承（功法、品性、理念）
- 應呈現師尊對弟子的期許與失望
- 弟子對師尊應有感恩與偶爾的反抗

---

### 6. 愛情線突兀

**禁忌**：主角與配角的感情無鋪墊，突然宣布相愛

**正確做法**：
- 感情線應在行走、決鬥、人事等環節中自然推進
- 相遇次數應與親密度相符
- 大的感情宣言應有關鍵事件驅動

---

### 7. 江湖人物無血肉

**禁忌**：配角只是工具人（幫主角、教主角、死給主角傷心）

**正確做法**：
- 每個重要配角都應有獨立的目標與軌跡
- 配角與主角的相遇應相互影響彼此
- 配角的離世應有實際的悲傷與後續影響

---

### 8. 現代元素混入

**禁忌**：故事設定在古代，卻出現現代用語、建築、習俗

**正確做法**：
- 每個地名、物品、習俗都應符合古代背景
- 若要現代改編，應明確標明為「現代仙俠」

---

### 9. 決鬥淪為數據對抗

**禁忌**：決鬥變成修為值的單純比較，無招式與品性的體現

**正確做法**：
- 決鬥應展現各自的劍法特色
- 應體現智謀與品性的作用（而非只看修為）
- 敗者應有說得過去的失敗原因

---

### 10. 道德說教

**禁忌**：以作者的名義論述人生、修道、品性，打破角色代入

**正確做法**：
- 道德觀應通過角色的行動與選擇來體現
- 不應有長篇獨白式的人生論述
- 複雜思想應分散在對話與內心中

---

## VIII. 語言鐵律

### 8.1 古韻文言的適度使用

**允許場景**：
- 古籍、秘籍、師尊教導
- 莊嚴場合的正式對話
- 環境的莊嚴氛圍營造

**禁用場景**：
- 主角內心獨白（應為現代心理）
- 日常輕鬆對話
- 動作描寫的主幹

**範例**：
```
【允許】秘籍云：「劍之一道，修身養性為先……」
【允許】長劍上人教訓：「爾之劍心猶未通透，需多磨練。」
【禁用】主角想：「余之修為未足，必當奮力……」
（應為：「我的修為還不夠，必須更努力……」）
```

---

### 8.2 劍術描寫的精確性

**規則**：
- 劍法招式應有明確的名稱與特徵
- 同一招式在多次出現時應保持一致
- 招式的威力應與使用者的修為相符

**範例**：
```
【含糊】「他揮動長劍，發出了強大的攻擊。」
【精確】「他運起丹田靈力，執劍向下一劈，青鋒劍泛起冷光，
        這是《青蓮劍訣》的第三式【青蓮初綻】，劍鋒帶著道韻，
        撕裂了空氣。」
```

---

### 8.3 禪意對白

**規則**：
- 高手之間的對話可帶有禪意與含蓄
- 但不應過度晦澀，導致讀者無法理解
- 禪意應來自真實的修行體驗，而非作者硬生生塑造

**範例**：
```
【過度禪意】「吾心無劍，劍在心外……」
（模糊且易引起疲勞）

【合理禪意】「你的劍太快了，卻不夠深。快劍傷人，深劍傷心。
            你要學的，不是更快，而是懂得什麼時候不出劍。」
（帶有修為體悟，但仍清晰易懂）
```

### 8.4 古代背景的描寫

**地名與建築**：
- 使用古代名稱（如：蜀山、嵩山派、長白山）
- 若為虛構，應具有古代合理性
- 建築應符合古代風格（殿堂、閣樓、石橋）

**衣著與飾物**：
- 衣著：白衣、道袍、錦衣、長衫
- 飾物：玉佩、劍穗、髮簪、扳指
- 避免現代服飾或配飾

**禮儀與習俗**：
- 拜師、受賞、決鬥前的禮儀應符合古代設定
- 茶文化、劍文化應有所體現
- 節慶與時序應符合農業文明背景
