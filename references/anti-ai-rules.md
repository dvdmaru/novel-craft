## A. 套話詞清單（Hedge Words）

### 定義
套話詞是削弱敘述確定性的詞彙，過度使用會導致文風虛浮、不夠有力。

### 清單

| 套話詞 | 用例 | 問題 |
|--------|------|------|
| 似乎 | 他似乎很生氣 | 削弱情感表達的確定性 |
| 可能 | 她可能會來 | 過度猶豫 |
| 或許 | 或許他是對的 | 含糊其辭 |
| 大概 | 大概有十個人 | 不夠精確 |
| 某種程度上 | 他某種程度上同意了 | 冗長且虛浮 |
| 一定程度上 | 一定程度上很有道理 | 冗長，削弱觀點 |
| 在某種意義上 | 在某種意義上他是贏家 | 過度修飾 |

### 檢測閾值

```
套話詞密度 = 套話詞出現次數 / (文本長度/1000)
如果密度 > 3 次/千字 → warning
```

### 修復建議

**原則**：用更確定、有力的表述替換套話詞

**改寫範例**

| ✗ 原文 | ✓ 改寫 |
|--------|--------|
| 他似乎很生氣 | 他怒目圓睜、拳頭緊握，顯然已經怒火中燒 |
| 她可能會同意 | 她遲疑了片刻，最終點頭同意 |
| 大概有十人 | 粗略估計有十人，也許更多 |
| 在某種程度上有些失望 | 他眼神黯淡，心裡湧起淡淡的失望 |
| 或許值得試一試 | 這想法不錯，值得一試 |

## B. 公式化轉折詞清單（Transition Words）

### 定義
轉折詞連接相反或補充的邏輯，但過度重複會導致句式公式化。

### 清單

| 轉折詞 | 用例 | 問題 |
|--------|------|------|
| 然而 | 然而，事情並非如此簡單 | 重複使用導致句式固化 |
| 不過 | 不過他還是決定去了 | 高頻使用顯得生硬 |
| 與此同時 | 與此同時，敵人也在行動 | 過度依賴導致生硬感 |
| 另一方面 | 另一方面，她有自己的想法 | 刻板的轉折方式 |
| 儘管如此 | 儘管如此，他堅持前進 | 過於正式，不自然 |
| 話雖如此 | 話雖如此，情況已經改變 | 過度修飾 |
| 但值得注意的是 | 但值得注意的是，他並非無敵 | 冗長且突兀 |

### 檢測閾值

```
同一轉折詞出現次數 ≥ 3 → warning
```

### 修復建議

**原則**：多樣化轉折詞使用，或用其他方式表達轉折（如直接敘述、對比、停頓）

**改寫範例**

| ✗ 原文 | ✓ 改寫 |
|--------|--------|
| 然而他沒有放棄。然而敵人已準備好。然而他仍在前進。 | 他沒有放棄。敵人早有準備。但這並未阻止他的腳步。 |
| 不過很快他明白了。不過事情變得更糟。不過他還活著。 | 很快他明白了。事情變得更糟。可他仍活著，這就夠了。 |
| 儘管如此他堅持。儘管如此她相信。儘管如此世界在改變。 | 他堅持著。她依舊相信。世界卻在悄然改變。 |

## C. 驚訝標記詞清單

### 定義
驚訝標記詞是 AI 模型常見的驚訝表達標記，過度使用會顯得生硬且 AI 痕跡明顯。

### 清單

| 標記詞 | 用例 | 問題 |
|--------|------|------|
| 仿佛 | 仿佛時間停止了 | AI 常用，過度使用不自然 |
| 忽然 | 忽然他明白了 | 過度使用，顯得突兀 |
| 竟 | 他竟敢這樣做 | AI 標記詞，頻繁出現為標誌 |
| 竟然 | 敵人竟然很弱 | 重複使用導致生硬感 |
| 猛地 | 他猛地轉身 | 動作描寫過度標記化 |
| 猛然 | 她猛然驚醒 | 與「猛地」重複 |
| 不禁 | 他不禁笑了出來 | 過度套話化的驚訝標記 |
| 宛如 | 宛如夢幻一般 | 過度使用導致虛浮 |

### 檢測閾值

```
驚訝標記詞密度 = 標記詞出現次數 / (文本長度/3000)
如果密度 > 1 次/3000 字 → warning
```

### 修復建議

**原則**：用具體的動作、感官描寫替換抽象的標記詞

**改寫範例**

| ✗ 原文 | ✓ 改寫 |
|--------|--------|
| 仿佛時間停止了 | 空氣彷彿凝固了，一切陷入無聲的靜止 |
| 他竟然活了下來 | 他活了下來，這令所有人都感到震驚 |
| 她猛地轉身 | 她身體一僵，猛地轉身，眼神中閃過殺意 |
| 不禁笑了出來 | 嘴角不由自主地上揚，發出了笑聲 |
| 宛如幻夢 | 這一切如同夢境般不真實，她甚至懷疑自己是否在做夢 |

## D. 段落等長檢測算法

### 定義
段落長度過於均勻（變異係數 CV < 0.15）會導致視覺節奏單調。

### 算法

```
1. 統計全篇每個段落的字數
2. 計算平均值（Mean）：所有段落字數的平均
3. 計算標準差（StdDev）：段落字數的標準差
4. 計算變異係數（CV）：
   CV = StdDev / Mean
5. 判斷：
   如果 CV < 0.15 → warning（段落過於均勻）
   如果 CV ≥ 0.15 → normal（段落分佈正常）
```

### 範例計算

假設某章有 6 個段落，字數分別為：100, 102, 99, 101, 103, 98

```
Mean = (100 + 102 + 99 + 101 + 103 + 98) / 6 = 100.5
StdDev ≈ 1.87
CV = 1.87 / 100.5 ≈ 0.0186
結論：CV < 0.15 → warning，段落過於均勻
```

### 修復建議

**原則**：製造段落長度的視覺變化，混合使用短段與長段

**改寫範例**

| ✗ 原文（所有段落 3-4 行） | ✓ 改寫（混合長度） |
|--------------------------|------------------|
| 他走進房間。房間很黑。他點亮了燈。光線照亮了一切。 | 他走進房間。黑暗中，一絲刀光劃過。他本能地躲開，點亮了燈。光線瞬間照亮了一切——一個身影站在角落，手中握著刀。 |

## E. 列表式結構檢測

### 定義
連續句子的前 2 字相同，≥ 3 句會導致敘述顯得列表化、機械化。

### 算法

```
1. 逐句檢查前 2 字（或首詞語）
2. 識別連續句子前 2 字相同的情況
3. 如果連續 ≥ 3 句前 2 字相同 → info（列表式結構）
```

### 範例檢測

✗ **列表式結構**：
```
他拿起刀。
他砍向敵人。
他看見鮮血。
他感到快意。
```
→ 「他」字連續 4 句開頭，檢測到列表式結構

✓ **改善版本**：
```
他拿起刀，砍向敵人。
鮮血濺起，他感到一陣痛快的快意。
```

### 修復建議

**原則**：調整句子開頭，使用合併句、倒序、被動語態等手法製造變化

**改寫範例**

| ✗ 原文 | ✓ 改寫 |
|--------|--------|
| 他走進房間。他看到敵人。他拔出刀。他沖上前去。 | 他走進房間，眼中掃過敵人的身影。刀光閃起，他已經沖到敵人面前。 |
| 她聽到聲音。她回頭看去。她看見了鬼魅。她嚇了一跳。 | 聲音傳來時，她本能地回頭。一個鬼魅般的身影現身，她瞬間僵住。 |
| 我拿起筆。我寫下文字。我思考著。我決定了。 | 筆尖在紙上舞動，文字逐漸成形。思考中，我做出了決定。 |

## F. 禁止語言模式（完整清單）

### 定義
以下語言模式具有明顯的 AI 或分析報告特徵，應避免在創意寫作中使用。

### F1. 分析報告式語言

這類詞彙來自學術或分析文本，在文學作品中顯得突兀、機械：

| 禁止詞彙 | 為什麼要禁止 | 替代表述 |
|---------|-----------|--------|
| 核心動機 | 太機械、分析化 | 真正的想法、內心的驅動 |
| 信息邊界 | 學術化術語 | 他不知道、隱瞞、隱秘 |
| 信息落差 | 分析報告用語 | 不了解、誤會、真相未明 |
| 核心風險 | 高度抽象化 | 危險、威脅、麻煩 |
| 利益最大化 | MBA 教科書風格 | 尋求最大收益、謀求好處 |
| 當前處境 | 報告式開場詞 | 現在的情況、眼下的困境 |

**禁用例子**
- ✗ 「他的核心動機是獲取權力」
- ✓ 「他渴望權力，這早已刻在骨子裡」

- ✗ 「存在信息落差，導致雙方誤會加劇」
- ✓ 「彼此都不了解對方的真實想法，誤會因此加深」

### F2. 「不是……而是……」句式

這種句式過於正式且分析化，不適合敘述文學：

| ✗ 禁止 | ✓ 改寫 |
|--------|--------|
| 這不是巧合，而是精心策劃的結果 | 這並非巧合——一切都在精心籌劃中 |
| 他不是無能，而是選擇了妥協 | 他不是無能的，只是選擇了退一步 |
| 她的行為不是背叛，而是自保 | 她的行為看似背叛，實則是為了活命 |

### F3. 破折號「——」的過度使用

過度使用破折號會導致敘述顯得機械、分析化：

| ✗ 原文 | ✓ 改寫 |
|--------|--------|
| 他終於明白了——他一直被騙了——而騙子就在眼前 | 他終於明白了。他一直被騙了。騙子就站在眼前，面帶冷笑。 |
| 這是機遇——也是陷阱——他必須小心 | 這既是機遇，也是陷阱。他必須萬分小心。 |

### F4. 元敘事語言

直接評價故事或角色的語言應避免：

| ✗ 禁止 | ✓ 改寫 |
|--------|--------|
| 值得注意的是，他做出了一個關鍵決定 | 那個決定改變了一切 |
| 這個轉折點很重要 | （直接敘述轉折，讓讀者自己感受其重要性） |
| 她的聲音帶著諷刺，這表明她很聰明 | 她冷冷一笑，嘲諷的聲調中透出聰慧 |

### F5. hook_id 與賬本式數據出現在正文中

任何形如「#hook_123」或「資源賬本：金幣 -50」的數據應絕對禁止：

| ✗ 禁止 | ✓ 改寫 |
|--------|--------|
| #hook_emotionalTurning 她突然哭了 | 她突然哭了，眼淚模糊了視線 |
| 資源賬本：金幣 -100 | （在故事敘述中表達花費） |

## G. 玄幻高疲勞詞清單

### 定義
以下詞彙在玄幻網文中被過度使用，導致讀者疲勞。應減少使用或用新鮮表述替換。

### 清單

| 高疲勞詞 | 用例 | 問題 | 替代表述 |
|---------|------|------|---------|
| 冷笑 | 他冷笑一聲 | 玄幻必備，極度高頻 | 嘴角冷冷上揚、低聲冷哼、眼神冷了下來 |
| 螻蟻 | 在我眼裡你們只是螻蟻 | 傲慢表達過度使用 | 渺小如塵埃、微不足道、不值一提 |
| 倒吸涼氣 | 眾人倒吸一口涼氣 | 驚訝表達固定化 | 眼神驟變、身體僵住、瞳孔驟縮 |
| 瞳孔驟縮 | 他的瞳孔驟縮 | 驚訝的慣用表達 | 眼神一冷、眼睛一瞪、眸光閃過 |
| 不可置信 | 臉上浮現不可置信的表情 | 驚訝表達套路化 | 眉頭皺起、嘴張得很大、一時無言 |
| 轟然炸裂 | 整個山峰轟然炸裂 | 戰鬥場景固定詞 | 爆炸、崩塌、在衝擊下碎裂 |
| 滿場死寂 | 整個會場滿場死寂 | 沉默表達過度使用 | 沒有人說話、氣氛凝固、無聲的寂靜 |
| 難以置信 | 難以置信的力量 | 驚訝衝擊詞高頻 | 超出想象的、難以承受的、令人震驚的 |

### 修復建議

**原則**：用具體的視覺、聽覺、感覺描寫替換抽象的高疲勞詞

**改寫範例**

| ✗ 原文 | ✓ 改寫 |
|--------|--------|
| 他冷笑一聲，眾人倒吸一口涼氣 | 他嘴角上揚，眼神如刀，眾人退後一步，感受到了殺意 |
| 在我眼裡你們都是螻蟻，瞳孔驟縮 | 你們在我眼裡微不足道，如塵埃般不值一提 |
| 轟然炸裂的山峰，滿場死寂 | 山峰在巨大的力量下碎裂，飛石四濺。沒有人敢出聲。 |
| 難以置信的力量 | 超出想象的強大力量、無法測度的能量 |

## H. 改寫建議範例

本章提供各類常見 AI 問題的詳細改寫範例。

### H1. 套話詞過多

**✗ 原文**
```
他似乎感到了某種程度上的失望，或許是因為她可能背叛了他。
在某種意義上，他覺得一定程度上有些後悔自己的信任。
```

**✓ 改寫 — 方案 A（簡潔有力）**
```
他感到了失望。她背叛了他，這一事實刺痛了他的心。
他開始後悔自己的信任，那純真的信任如今成了笑柄。
```

**✓ 改寫 — 方案 B（細節豐富）**
```
失望如潮水般襲來，他無法呼吸。
她背叛了他——這個事實比任何言語都沉重。
他的心在滴血，後悔與憤怒交織，吞沒了他的理智。
```

---

### H2. 轉折詞重複

**✗ 原文**
```
然而他沒有放棄，反而更加堅定。然而敵人也不是易與之輩。
然而最終他還是輸了，這令人意外。
```

**✓ 改寫 — 方案 A（多樣化轉折）**
```
他沒有放棄，反而更加堅定。
但敵人也不是易與之輩，雙方勢均力敵。
最終，他還是輸了。這令所有人都感到震驚。
```

**✓ 改寫 — 方案 B（省略轉折詞）**
```
他沒有放棄。敵人同樣強大。
他輸了——在最後關頭，力量悄然耗盡。
```

---

### H3. 列表式結構

**✗ 原文**
```
他拿起刀。他轉身面對敵人。他發出了怒吼。他沖了上去。
敵人舉起盾牌。敵人做好了防守。敵人沒有絲毫退縮。
```

**✓ 改寫 — 方案 A（合併句）**
```
他拿起刀，轉身面對敵人，發出一聲怒吼後沖了上去。
敵人舉起盾牌，做好防守，眼中沒有半分退縮。
```

**✓ 改寫 — 方案 B（交替敘述）**
```
他拿起刀，怒吼著沖向敵人。
敵人舉起盾牌，冷冷地等待著。
刀與盾在空中碰撞，火花飛濺。
```

---

### H4. AI 標記詞過多

**✗ 原文**
```
仿佛時間停止了，她忽然明白了真相。
她竟然活下來了，宛如奇跡一般。
他不禁感到驚訝，猛地站起身來。
```

**✓ 改寫 — 方案 A（刪除標記詞）**
```
時間似乎停止了，真相在那一刻變得清晰。
她活下來了，這本身就是奇跡。
驚訝衝擊了他的心智，他猛地站起身。
```

**✓ 改寫 — 方案 B（加入感官細節）**
```
空氣凝固了，真相在她眼前展開。
她活著。呼吸著，感受著心臟的跳動——奇跡成真。
驚訝如電流穿過全身，他蹭地站起，椅子向後倒去。
```

### H5. 高疲勞詞

**✗ 原文**
```
敵方的首領冷笑一聲，在他眼裡，對手都是螻蟻。
眾人倒吸一口涼氣，瞳孔驟縮。
整個戰場轟然炸裂，滿場死寂隨之而來。
```

**✓ 改寫 — 方案 A（具體動作）**
```
敵方首領嘴角上揚，眼神如刀。他甚至懶得看這些對手——在他眼裡，他們只是墊腳石。
眾人的呼吸驟停，有人的手開始發抖。
衝擊波席捲而來，整個戰場在巨響中塌陷。寂靜籠罩了一切，沒有人敢動彈。
```

**✓ 改寫 — 方案 B（內心獨白）**
```
敵方首領冷冷地掃過眾人，嘴角帶著輕蔑的弧度。這些螻蟻還敢與他為敵，真是可笑。
對面的人驚恐地往後退，其中一人的劍落到了地上。
地動山搖，戰場在巨大的能量下支離破碎。一切都靜了下來，只剩下落石的聲音。
```

### H6. 分析報告式語言

**✗ 原文**
```
這不是巧合，而是精心策劃的結果。
他的核心動機是獲取更多的力量。
存在信息落差，導致他無法做出正確決定。
他當前的處境非常危險，面臨著核心風險。
```

**✓ 改寫 — 方案 A（故事化敘述）**
```
這一切都在預料之中——她早就在布局。
他渴望力量，這個執念已經刻進了靈魂。
他不知道真相，所以做錯了選擇。
現在他陷入了危機，死亡近在咫尺。
```

**✓ 改寫 — 方案 B（情感化敘述）**
```
沒有巧合。她早已布下天羅地網，等著他自投羅網。
對力量的渴望吞沒了他的理智，他已經無法自拔。
他被蒙在鼓裡，每一步都踩中了敵人的陷阱。
危險逼近，他能感受到死神的呼吸。
```

### H7. 段落等長導致的單調

**✗ 原文**（所有段落 50-60 字，3-4 行）
```
他走進了黑暗的森林。
樹木在風中發出聲響。
他能感受到危險的氣息。
前方傳來了奇怪的聲音。
```

**✓ 改寫 — 方案 A（製造視覺節奏）**
```
他走進了黑暗的森林。

樹木在風中發出詭異的聲響。

前方傳來了奇怪的聲音，短促而急促，如同什麼東西在掙扎。
他能感受到危險正在接近，這種感覺刺痛了他的神經。
```

**✓ 改寫 — 方案 B（不同長度混合）**
```
森林很黑。

樹木在風中發出詭異的聲響，如同呢喃的低語。他已經習慣了這種聲音，但今晚的聲響卻帶著不同的韻味——絕望與恐懼交織。

危險逼近了。

前方的聲音越來越清晰。
```

## I. 檢測與修復工作流

### 步驟 1：自動掃描（規則引擎）

使用工具掃描以下維度：
- 維度 20：段落等長（CV < 0.15）
- 維度 21：套話詞密度（> 3 次/千字）
- 維度 22：公式化轉折（同詞 ≥ 3 次）
- 維度 23：列表式結構（連續 ≥ 3 句）

### 步驟 2：人工審查（LLM 審計）

檢查以下問題：
- 高疲勞詞使用（見附錄 G）
- AI 標記詞過多（驚訝詞、套話詞）
- 禁止語言模式（見附錄 F）
- 分析報告式語言
- 信息越界與知識庫污染

### 步驟 3：修復優先級

**P1（優先修復）**：
- 分析報告式語言
- 禁止詞彙（hook_id、賬本數據等）
- 核心高疲勞詞（冷笑、螻蟻、轟然炸裂）

**P2（重點修復）**：
- 套話詞密度過高
- 轉折詞重複
- 段落等長

**P3（優化修復）**：
- AI 標記詞
- 列表式結構

## J. 快速參考表

### 禁止語言總結表

| 類別 | 禁止 | 改寫方向 |
|------|------|---------|
| 套話詞 | 似乎、可能、大概等 | 用具體描寫替換 |
| 轉折詞 | 然而(≥3次)、不過 | 多樣化或刪除 |
| 標記詞 | 竟、竟然、仿佛、不禁 | 用動作/感覺替換 |
| 報告式 | 核心動機、信息落差 | 故事化敘述 |
| 分析式 | 「不是……而是」 | 用破折號或直述 |
| 符號 | hook_id、——過多 | 刪除或用其他標點 |
| 高疲勞詞 | 冷笑、螻蟻、倒吸涼氣 | 視覺/聽覺細節描寫 |

### 檢測閾值總結表

| 維度 | 檢測公式 | 閾值 | 級別 |
|------|---------|------|------|
| 段落等長 | CV = StdDev / Mean | CV < 0.15 | warning |
| 套話詞 | 密度 = 次數 / (字數/1000) | > 3 次/千字 | warning |
| 轉折詞 | 同詞出現次數 | ≥ 3 次 | warning |
| 列表結構 | 連續句前 2 字相同 | ≥ 3 句 | info |
| 標記詞 | 密度 = 次數 / (字數/3000) | > 1 次/3000字 | warning |
