# 都市題材完整規則手冊

---

## I. 都市題材概述

**定義**：當代或特定歷史時期的真實城市背景，以現實規則為基礎，融入幻想或虛構衝突。

**核心特徵**：
- 地點真實或虛構但符合現實邏輯
- 角色面臨現實層面的挑戰（金錢、身份、人際）
- 超自然或架空設定（若有）需與現代生活相容
- 時代背景具體明確

**常見子類型**：
- 商戰文（企業競爭、財務戰爭）
- 重生文（穿越回過去，改變現在）
- 隱形富豪文（身份隱瞞、實力隱藏）
- 都市超能文（超自然力量在現代社會的應用）
- 職場文（升職、跳槽、人脈管理）

---

## II. 章節類型分類

### 1. 商戰章

**定義**：涉及商業談判、企業併購、市場競爭、資本運作的章節

**特徵**：
- 信息密度高，涉及商業術語
- 結果可測量（股價、訂單、合同成立）
- 多方利益對抗與平衡

**常見結構**：
```
信息獲取 → 策略制定 → 談判或交涉 → 局勢轉折 → 目標達成/失敗
```

**節奏要點**：
- 商業邏輯必須自洽（不能無理由漏洞）
- 對手應有合理的反制措施
- 勝利應通過智謀而非運氣

**爽點類型**：
- 談判反轉：預期B，結果出現C，局勢翻轉
- 底牌亮出：隱藏的籌碼或信息突然使用
- 計謀得逞：多步騙局最終收網

**舉例**：《杜拜的老鼠藥》中的股票戰爭場景 - 隱形富豪通過信息差與資本優勢反向做空對手

**撰寫時限**：2000-4000字（允許較長，承載複雜商業邏輯）

---

### 2. 社交章

**定義**：人物在社交場合（宴會、聚會、酒吧、辦公室）的互動與關係推進

**特徵**：
- 對白為主，環境描寫為輔
- 人物性格在交談中逐步暴露
- 可能埋伏隱藏信息或新人物

**常見結構**：
```
場景設定 → 人物集合 → 對話與互動 → 新信息或衝突 → 散場或深化
```

**節奏要點**：
- 對白應自然且各具特色（不同人物應有不同說話方式）
- 不應全為說教式對話（應融入行動與表情）
- 社交場面的緊張感應來自潛在衝突，而非直接對抗

**常見場景**：
- 商務晚宴（談判與試探）
- 朋友聚會（私人感受與秘密披露）
- 辦公室閒談（辦公室政治與八卦）
- 聯誼或相親（身份查證與印象形成）

**舉例**：主角在高級酒吧與合作方首次接觸，表面談論合作，實際在試探對方的底細與立場

**撰寫時限**：1500-2500字

---

### 3. 布局章

**定義**：為後續商戰或社交衝突埋伏信息、介紹新角色、設置新目標的章節

**特徵**：
- 以懸念或未解決的問題結尾
- 多方利益與衝突開始顯露
- 讀者獲得不對稱信息

**常見結構**：
```
當前困境呈現 → 新信息透露 → 新敵手或盟友出現 → 下一步方向不清 → 懸念
```

**節奏要點**：
- 每個布局章應明確至少一個新的「敵手」或「目標」
- 新人物應帶有清晰的立場（敵對、合作或中立）
- 時間線應明確（今天、下週、某個具體日期）

**舉例**：主角發現上司正在暗中進行併購計畫，自己的部門將被裁撤，局勢變得複雜

**撰寫時限**：1800-2800字

---

### 4. 過渡章

**定義**：日常工作、人物成長、時間推進的章節，為重大事件蓄勢

**特徵**：
- 相對平靜，無重大衝突
- 角色的日常習慣與工作細節
- 為後續事件埋伏伏筆

**常見結構**：
```
早晨日常 → 工作推進 → 與同事互動 → 小規模發現或進展 → 夜間思考
```

**節奏要點**：
- 避免連續3章過渡（讀者容易疲勞）
- 日常中應暗示後續重大事件
- 職業細節應真實（若描寫律師，應懂基本法律知識）

**舉例**：主角在辦公室處理日常工作時，無意中發現某份文件，引發新的懷疑

**撰寫時限**：1200-2000字

---

### 5. 回收章

**定義**：兌現伏筆、推進長期計畫、人物關係深化、身份秘密揭露的章節

**特徵**：
- 高情感衝擊力
- 包含長期懸念的解答或轉折
- 可能改變角色的社會地位或人脈

**常見結構**：
```
期待或緊張氛圍 → 真相/承諾兌現 → 角色反應 → 新局面形成
```

**節奏要點**：
- 重要伏筆的回收應不早於埋下後的4-7章
- 回收時應有新的懸念接手
- 關係轉折應有具體事件驅動

**舉例**：主角終於查實上司的背叛，決定反擊；或隱瞞多年的身份在關鍵時刻被揭露

**撰寫時限**：2000-3500字

## V. 節奏規則

### 5.1 反饋週期

**核心規則**：每2-3章一個小回報

**定義**：主角的行動在2-3章內產生可感知的進展（小勝、小挫、信息獲得）

**反饋類型**：
- **商業反饋**：訂單達成、競爭者敗退、股價上升
- **關係反饋**：人脈拓展、信任加深、衝突解決
- **身份反饋**：升職、獲得新身份、秘密洩露
- **信息反饋**：發現真相、獲得關鍵信息
- **心理反饋**：信心增強、目標明確、心態轉變

**舉例（反面）**：
```
第10章：主角決定參加高級商務宴會，尋求合作
第11-12章：準備與參加（無反饋）
第13章：才發現宴會無人感興趣（超過3章，反饋太遲）
```

**舉例（正面）**：
```
第10章：主角決定參加高級商務宴會，尋求合作
第11章：通過朋友介紹，認識了關鍵人物A（信息反饋 + 人脈反饋）
第12章：與A深談，發現合作機會但有隱藏條件（商業反饋 + 新伏筆）
第13章：開始評估是否接受合作（心理反饋）
```

---

### 5.2 爽點分布

**每章應含一個小爽點**，大爽點則按照章節類型分布

**推薦爽點序列**（每4章為一輪）：
```
第1章：商戰勝利/身份顯露
第2章：人脈拓展/意外發現
第3章：計謀得逞/關係深化
第4章：危機反轉/秘密揭露
（第5-8章循環重複）
```

**大爽點與小爽點區分**：
- 大爽點（2000-3000字）：關鍵商戰、身份大揭露
- 小爽點（500-1000字）：日常談判勝利、新朋友認識

## VI. 爽點類型詳解

### 1. 商戰勝利

**定義**：主角通過智謀或信息優勢在商業談判或競爭中獲勝

**要素**：
- 對手的實力與動機清晰
- 主角的計畫與執行有邏輯
- 反轉點明確且令人信服

**範例**：
```
主角知悉對方資金鏈即將斷裂，故意在談判中延遲簽約，
迫使對方因缺乏流動資金而降低條件，主角最終以更優惠的條件簽約。
```

**字數**：2000-3000字

---

### 2. 身份顯露

**定義**：主角隱瞞的身份、背景或真實實力在關鍵時刻被揭露或自我確認

**要素**：
- 隱瞞應有充分的理由（安全、策略、私人原因）
- 揭露時應改變局勢認知
- 可能帶來新的盟友或敵手

**範例**：
```
主角一直在競爭對手面前裝作普通員工，實際上是總裁之子。
在關鍵時刻，對方無意發現了真相，整個關係動態瞬間改變。
```

**字數**：2000-3000字

---

### 3. 人脈拓展

**定義**：主角認識了具有戰略價值的新人物，拓展了人脈網絡

**要素**：
- 新人物應有明確的身份與能力
- 相遇應有合理的場景與動機
- 新人物的加入應改變主角的可選方案

**範例**：
```
主角在酒吧無意認識了某銀行行長，通過對話發現此人與自己的對手有舊仇，
建立初步盟友關係，為後續融資開路。
```

**字數**：1500-2500字

---

### 4. 計謀得逞

**定義**：主角精心設計的多步計畫最終取得成效

**要素**：
- 計謀應在前期埋伏線索
- 執行過程應有風險與波折
- 結局應有意外的轉折或額外收益

**範例**：
```
主角在3章前就設計了一個陷阱：通過假信息誘導競爭對手簽署不利條款，
現在終於到了收網的時刻，對手才意識到被套路。
```

**字數**：1800-2500字

---

### 5. 危機反轉

**定義**：在似乎無法解決的困境中，主角找到了突破口，局勢逆轉

**要素**：
- 困境應真實且艱難
- 突破口應來自前期的鋪墊或角色的創新思維
- 反轉應彰顯主角的能力

**範例**：
```
主角被對手設局，合同即將被撕毀，公司瀕臨破產。
此時，主角想起多月前與某人的對話，立刻聯繫對方，
對方同意臨時融資，危機解除。
```

**字數**：1800-2800字

---

### 6. 秘密揭露

**定義**：長期隱瞞的秘密被揭露，改變了角色與讀者的認知

**要素**：
- 秘密應在前期埋伏，而非突然出現
- 揭露應有具體的證據或見證
- 揭露後應產生新的衝突或和解

**範例**：
```
主角的助理被發現是對手的臥底，已經洩露了所有商業機密。
主角陷入危機，需要迅速應對。
```

**字數**：2000-3000字

## VII. 年代約束規則

都市文必須遵守時代背景的技術與社會規則。

### 7.1 時間背景的確定

**應在開篇或前五章明確說明**：
- 現實時代年份（2024年、2010年等）或虛構年份（「近未來2035年」）
- 核心城市與行業背景

**違反舉例**：
```
【違反】故事設定在2010年，第15章主角用抖音發視頻
【正確】故事設定在2020年後，主角才能使用抖音；
        或故事設定在2010年，主角用微博發信息
```

---

### 7.2 科技與通訊

**2000-2010年**：
- 手機：功能機、早期智能機（iPhone首發2007年）
- 通訊：短信、QQ、MSN
- 工作：電話、郵件、傳真
- 娛樂：網吧、電視劇

**2010-2015年**：
- 手機：智能機普及
- 通訊：微信出現（2011年），微博
- 工作：郵件、視頻會議初現
- 娛樂：手機遊戲、微博

**2015-2020年**：
- 手機：各類App成熟
- 通訊：微信主導，短視頻興起
- 工作：雲文檔、遠程會議、Slack等工具
- 娛樂：短視頻、直播

**2020年至今**：
- 手機：5G、各類超級App
- 通訊：微信企業號、釘釘等
- 工作：遠程辦公普遍
- 娛樂：抖音、B站、小紅書

**檢查清單**：
```
□ 時代背景已在前5章明確說明
□ 手機型號與年份相符
□ 社交軟體符合年代（不能反向時空穿越）
□ 上班族使用的工具符合年代
□ 消費地點符合城市當時狀況（如：2010年不可能有某商場，因為當時未建）
```

---

### 7.3 社會風俗與經濟背景

**房價與房產觀念**：
- 2010年前：房產是奢侈品
- 2010-2015年：房產成為家庭資產重點
- 2015年後：房產市場分化，一二線與三四線差異巨大

**職業與薪資**：
- 2010年：本科畢業薪資2000-3000元
- 2015年：本科畢業薪資4000-6000元
- 2020年：本科畢業薪資6000-10000元

**汽車與出行**：
- 2010年前：自駕車較少，出租車主導
- 2015年：私家車增加，滴滴等打車軟體出現
- 2020年後：新能源車普及，出行多元化

## VIII. 題材禁忌

### 1. 商業邏輯BUG

**禁忌**：商業決策無理由或違反基本商業常識

**正確做法**：
- 商業決定應有明確的利益驅動
- 若使用專業術語，應確保其使用正確
- 可查閱相關行業的基本規則

**違反舉例**：
```
【違反】主角突然決定虧本銷售產品，理由不明
【正確】主角為了快速佔領市場份額而採取虧本策略，
        明確表述這是短期戰略，目標是什麼，何時轉向盈利
```

---

### 2. 時間邏輯崩潰

**禁忌**：角色的時間安排無法自洽（同時出現在兩個地點、工作與私生活衝突未交代）

**正確做法**：
- 在 current-state.md 中明確角色的時間表
- 每次時間跳躍都應明確說明（「第二天」、「一週後」）
- 如需時間衝突，應主動交代解決方案

**違反舉例**：
```
【違反】上午9點在北京開會，下午3點出現在上海簽約（無說明交通時間）
【正確】上午9點開會結束後，立即坐高鐵前往上海（4小時），
        下午5點左右到達，與客戶晚餐時簽約
```

---

### 3. 人物性格崩壞

**禁忌**：角色的決定突然違反其既有的性格與價值觀，無故事原因

**正確做法**：
- 使用 emotional-arcs.md 追蹤性格變化的動因
- 大的性格轉變應有關鍵事件驅動（不能無故）
- 新的決定應與角色的成長軌跡相符

**違反舉例**：
```
【違反】一向謹慎保守的主角，突然在無人支持的情況下孤注一擲投資失敗項目
【正確】主角經歷多次失敗與自我反思（前期鋪墊），
        逐漸明白「謹慎也是一種風險」，才開始願意承擔更大風險
```

---

### 4. 對白過度說教

**禁忌**：角色的對話變成了作者直接發表觀點或解釋（打破第四堵牆）

**正確做法**：
- 觀點應透過角色的行動與選擇來體現
- 對白應是角色真實的交流，而非教科書式的說明
- 複雜思想應分散在多個對話中，而非一次性傾倒

**違反舉例**：
```
【違反】「你知道嗎，現在經濟形勢是這樣的，股市波動與……
        所以我們應該……」（冗長說教）
【正確】「市場上升，我們要慎重。」「為什麼？」
        「前兩年的崩盤才過去，誰都該記得。」（自然交流）
```

---

### 5. 主配角失衡

**禁忌**：配角的能力與篇幅超越主角，喧賓奪主

**正確做法**：
- 在 subplot-board.md 中為配角明確定位
- 配角應有明確的輔助角色功能（顧問、對手、夥伴）
- 如果配角很出彩，應考慮轉換為雙主角或多主角結構

**違反舉例**：
```
【違反】主角是CEO，但每次重大決定都是秘書做出來，主角只點頭
【正確】秘書提供分析，主角做決定；或者明確表述秘書是真正的幕後主角
```

---

### 6. 女性角色物化

**禁忌**：女性角色存在的唯一目的是搭配主角，無獨立目標與行動

**正確做法**：
- 女性配角應有獨立的職業目標與人生軌跡
- 感情線應建立在互相尊重的基礎上
- 避免將女性角色簡化為「溫柔賢淑」或「妖豔禍水」

---

### 7. 階級想像不真實

**禁忌**：對富人生活、貧困生活、中產生活的描寫過於刻板或浪漫化

**正確做法**：
- 研究不同階級的真實生活細節
- 避免獵奇式的描寫（「富人就是奢侈」、「窮人就是善良」）
- 呈現人物的複雜性與多樣性

---

### 8. 工作細節虛假

**禁忌**：涉及特定行業時，專業細節錯誤或過於簡化

**正確做法**：
- 涉及律師、醫生、會計等專業時，應查證基本規則
- 或明確表述為虛構背景，避免讀者混淆
- 可在作者後記說明參考資料

**違反舉例**（假設故事設定為律師文）：
```
【違反】律師隨意在法庭上推翻證人證詞，無需任何程序
【正確】律師通過法庭辯論、法律程序逐步瓦解對方證人的可信度
```

---

### 9. 感情線倉促

**禁忌**：主角與配角的感情線進展太快（2-3章就宣布戀愛），無鋪墊

**正確做法**：
- 使用 emotional-arcs.md 與 character-matrix.md 追蹤感情進度
- 相遇次數與親密度應相符
- 大的感情宣言應有關鍵事件驅動

**違反舉例**：
```
【違反】主角與A第1章認識，第3章就說「我愛你」
【正確】主角與A第1章認識，第2-6章多次互動，
        第7章才在危機中確認感情，第8章宣告
```

---

### 10. 懸念過度拖沓

**禁忌**：伏筆埋下後超過15章未推進或回收，讀者遺忘

**正確做法**：
- 使用 pending-hooks.md 追蹤伏筆進度
- 重要伏筆應在4-8章內有推進
- 次要伏筆應在8-12章內有推進

---

## IX. 語言鐵律

### 9.1 現代中文規範

**主角內心獨白**：
- 應使用現代白話文
- 可帶有口語化色彩（符合人物年齡與背景）
- 避免文言文或過度書面語

**範例**：
```
【違反】凌雲想：「吾不能退縮，定當奮起……」（古文，不符合現代心理）
【正確】凌雲想：「我不能就這樣放棄，必須找到辦法……」
```

---

### 9.2 職業術語的使用

**規則**：
- 涉及真實行業時，術語應準確使用
- 若為虛構行業，應明確定義術語
- 過度堆砌術語會降低可讀性

**範例**：
```
【合理】「這份財務報表顯示，公司的現金流出現問題。」
【過度】「這份EBITDA對比FCF的多維分析表明，運營效率指標需優化。」
        （除非特意營造專業感，否則過度）
```

---

### 9.3 地名的真實與虛構

**真實城市**：
- 地名、建築、交通應符合現實（或特定年代的現實）
- 不能隨意杜撰地點位置

**虛構城市**：
- 應清晰地標明為虛構（如「城市名為X市」）
- 內部邏輯應自洽

**避免混用**：
```
【違反】故事設在北京，但描寫北京有滄海桑田般的變化（混淆真實與虛構）
【正確】故事設在虛構的「中原市」，融合多個真實城市的特點
```

---

### 9.4 對白風格

**不同背景的角色應有不同的對白特徵**：
- 受過高等教育的人：用詞精準，句式複雜
- 基層工作者：用詞簡單，句式簡潔，可帶地域口音
- 老年人：可能用詞陳舊，節奏緩慢
- 年輕人：可能使用網絡用語，節奏快

**範例**：
```
【CEO對話】「我認為這個項目的ROI不夠理想，我們需要重新評估。」
【工人對話】「這活兒不划算，不接。」
【父親對話】「孩子，你這樣做是不是太衝動了？」
【年輕人對話】「這個plan太絕了，我們幹了！」
```

```markdown
- [ ] 高疲勞詞彙已掃描與替換

- [ ] 人物時間安排可自洽（不能同時兩地）
- [ ] 人物決定符合既有性格或有故事原因解釋
- [ ] 地點描寫符合年代與城市現實
- [ ] 使用的技術/軟體符合故事年份

- [ ] 設定一致性檢查（人物性格、地點、金額等）
- [ ] pending-hooks 已檢查伏筆推進（是否有4-8章未進展的伏筆）
- [ ] 新人物介紹（若有）已明確身份與立場
- [ ] 商業數據（股價、合同額等）已記錄，便於後續參考

### 人物檢查
- [ ] 對白符合各角色的教育背景與職業
- [ ] 不同性別角色有平等的篇幅與目標
- [ ] 感情線（若有）有明確的相遇次數與事件支撐
- [ ] character-matrix 已更新新相遇或關係變化
- [ ] emotional-arcs 已記錄角色心態變化

### 細節檢查
- [ ] 涉及專業行業的細節已驗證（或明確為虛構）
- [ ] 現實城市的地點、交通符合現況（或特定年代）
- [ ] 消費地點（餐廳、商場）符合時代與城市背景
- [ ] 手機、社交軟體的使用符合故事年份
- [ ] 薪資、房價等社會現象符合故事背景
```
